# 23 账本和断点续跑

## 1. 账本三件事

| 记什么 | 例子 |
|---|---|
| 钱 | spent: 19.9493 元 |
| 次 | calls: 276 次 |
| 上限 | CAP_MONEY / CAP_CALLS |

每次调用后立即写账：`spent += fee`、`calls += 1`。触顶立即停，不重试。预算是授权的一部分，超支等于违规。

## 2. 断点续跑

批次脚本开始时先数已完成调用，续跑时跳过、不重复计费：

```python
done = [f for f in os.listdir(RAW) if f.endswith(".json")]
n_call = len(done)
spent = sum(json.load(open(os.path.join(RAW, f)))["fee"] for f in done)
```

每个响应落盘时存 fee、request_id、usage、finish_reason。中断后能从盘上恢复全部状态。

## 3. 失败不计费的部分

网络超时、HTTP 404、鉴权错误没有 usage，不产生费用，但都记进日志。404 意味着模型名不存在：立即关闭该路径，换可用模型，别对着同一个报错重试。

## 4. 每批跑完出一张小账

本批用了几次、花了多少、账本余额多少。批次之间不许因为"这批没产出"临时换策略，策略变更要重新授权。
