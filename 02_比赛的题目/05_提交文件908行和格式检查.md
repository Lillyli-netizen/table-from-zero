# 05 提交文件：908 行和格式检查

[目录](../README.md)｜先修：[题干题型和答案格式](04_题干题型和答案格式.md)｜下一章：[分数怎么算](06_分数怎么算.md)

## 1. 提交文件只有两列

`id, answer`，908 行，一行一题。平台按 id 对表，答案按 answer_format 解析。

## 2. 交卷前必做的预检

| 检查 | 内容 | 不过的后果 |
|---|---|---|
| 行数 | 恰好 908 | 按平台规则可能拒收或计错 |
| id 唯一 | 无重复无缺失 | 对表错位 |
| 格式 | 每个答案按其 format 严格解析 | 整份拒收 |
| 回读 | 写进 xlsx 再读出来逐题一致 | 编码事故 |
| 哈希 | SHA-256 存档 | 版本混乱 |

回读检查防的是 xlsx 写入时的隐形改动：数字被 Excel 转成科学计数法、长数字末位变 0。写完再读一遍，逐题比对字符串。

## 3. 生成候选的标准动作

1. 从可追溯基线重建全量 908 行，记录父版本和来源。
2. 只改有证据的题，逐题记录改动来源。
3. 跑五项预检。
4. 算 SHA-256，连同改动清单一起存档。

## 4. 练习

1. 写一个预检函数，输入 xlsx，输出五项检查结果。
2. 造一个 id 重复的文件，看预检怎么拦。
3. 验证一次回读：写 `'00123'` 进 xlsx，读出来是什么。
