# 04 题干、题型和答案格式

[目录](../README.md)｜先修：[分辨率和渲染](../01_表格从哪里来/03_分辨率和渲染.md)｜下一章：[提交文件](05_提交文件908行和格式检查.md)

## 1. 每道题由五个字段组成

| 字段 | 例子 | 用途 |
|---|---|---|
| id | 243 | 交卷时的唯一键 |
| file_name | 006.pdf | 来源文件 |
| question | 扣子的产品功能是什么？ | 题干 |
| question_type | extract / structure | 题型 |
| answer_format | string / number / json / json_array | 答案格式 |

`answer_format` 决定答案怎么写，也决定程序怎么校验。读题先读格式，再读题干。

## 2. 四种格式的写法

| 格式 | 写法示例 | 常见错误 |
|---|---|---|
| number | `95250987.68` | 带千分位逗号、带单位"元" |
| string | `Stitch type` | 抄成整句解释 |
| json | `{"row_count": 2, "col_count": 3, ...}` | 键名拼错 |
| json_array | `["A", "B", "C"]` | 写成 Python 单引号列表 |

一道 `json_array` 题写成 `['A', 'B']`，平台直接报 `answer for question ID 243 isn't valid JSON`——整份提交按非法处理。这是真实发生过的教训。

## 3. 题型决定做法

- **extract**：从表里抠一个值或一串值。读准一处就行。
- **structure**：恢复表格结构，要合并信息和跨度。必须走读图路线。

## 4. 每次写答案前过三道闸

1. 格式闸：写出来的东西能被严格解析吗？
2. 键名闸：json 题的键名和模板一致吗？
3. 逐字闸：string 题是原文抄录还是转述？

三道闸全过才进候选文件。
