# 02 文本层：PDF 自带的隐藏文字

[目录](../README.md)｜先修：[PDF扫描件和图片](01_PDF扫描件和图片.md)｜下一章：[分辨率和渲染](03_分辨率和渲染.md)

## 1. 文本层是什么

电子 PDF 的每个字都是文字对象，带四元组坐标 `(x0, y0, x1, y1)` 和词内容。pymupdf 的 `get_text("words")` 把它们全部倒出来。文本层是零成本证据：不调模型、不要钱、可复算。

## 2. 从词列表重建表格网格

词列表没有表格结构，只有一堆带坐标的词。重建分两步：

1. 按 y 中心聚类成行：同一行的词 y0 相近（容差取字高的三分之一）。
2. 行内按 x 中心聚类成列：同一列的词横向对齐。

```python
import pymupdf
doc = pymupdf.open("006.pdf")
words = doc[0].get_text("words")   # (x0, y0, x1, y1, word, ...)
```

## 3. 重建结果长什么样

| 行 | 列1 | 列2 | 列3 |
|---|---|---|---|
| y≈120 | 长期借款 | 95,250,987.68 | 期末余额 |
| y≈160 | 租赁负债 | 88,132,323.23 | 期末余额 |

按坐标聚出来的行列表，就是表格的骨架。答案里的每个数值都能回到"第几行第几列"，这就是**数值溯源（provenance）**。

## 4. 文本层的三个限制

1. 没有合并信息：rowspan/colspan 不在文本层里，只有结构题要从图上拿。
2. 没有颜色：底纹区分的表头识别不了。
3. 可能缺字：财务符号 `¥`、特殊连字符有时丢失。

## 5. 练习

1. 打开任一电子 PDF，数一数第一页有多少行、多少列。
2. 任取一个数值，写出它所在行的完整行文本。
3. 找一个文本层重建错位的例子，说明是 y 容差太大还是太小。
