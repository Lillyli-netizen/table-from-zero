# 03 分辨率和渲染：把 PDF 页变成图

## 1. 为什么需要渲染

本项目采用图片接口，其他接口可能直接支持 PDF。把页变成图的过程叫**渲染（render）**，输出分辨率受 DPI 控制，可读性还取决于原文件和压缩。

| DPI | 一张 A4 页的像素 | 字有多大 |
|---|---|---|
| 72 | 595×842 | 模糊，小字看不清 |
| 170 | 1406×1991 | 比赛用的档位 |
| 300 | 2480×3508 | 清楚，但文件大 |

DPI 太低，小数字糊掉；DPI 太高，图片字节超限，编码前要压缩，两头都吃亏。比赛链路用 170。

## 2. 渲染代码就三行

```python
import pymupdf
doc = pymupdf.open("006.pdf")
pix = doc[0].get_pixmap(dpi=170)
pix.tobytes("png")
```

## 3. 压缩的次序

模型接口对单图字节有上限，超限要降质。以下是历史配置，需验证数字和符号可读性：

1. 长边缩到 2600 以内。
2. 转 JPEG，质量 90。
3. 仍超限再降长边到 1100，最低档。

每一步都只降一点点。直接把质量砍到 50 会把小数点糊掉。

## 4. 练习

1. 把同一页按 72 和 170 各渲一次，肉眼对比小号数字。
2. 记录 170 DPI 下 PNG 和 JPEG 的字节差。
3. 找出长边 2600、质量 90 仍超限的页，写降级后的实际字节。
