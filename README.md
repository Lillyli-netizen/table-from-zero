# table-from-zero

从零认识表格识别比赛的基本功。读完能看懂一场多模态表格识别比赛的完整流程：文件从哪里来、题目怎么读、模型怎么用、答案怎么验证、提交怎么管理。

本仓库讲原理和基本功，全部例子取自一场真实比赛（908 道题、PDF 与图片混合、阿里云千问系列模型）。动手代码和历史证据见 [tianchi-table-pipeline](https://github.com/Lillyli-netizen/tianchi-table-pipeline)。历史成绩与调用统计需关联原始记录，评分、接口限制及模型许可按对应版本规则核对。

具体实验与 Agent 分工见 [熟练选手的比赛流程](熟练选手的比赛流程.md)。

## 章节地图

| 部分 | 章节 | 内容 |
|---|---|---|
| 01 表格从哪里来 | 01–03 | PDF、扫描件、图片；文本层；分辨率与渲染 |
| 02 比赛的题目 | 04–06 | 题干与答案格式；提交文件；分数 |
| 03 单元格和坐标 | 07–10 | 单元格与 bbox；合并单元格；表头；空白格 |
| 04 让模型读表 | 11–16 | 喂图；提示词契约；截断；两种读法；票数；常见错误 |
| 05 验证和修正 | 17–22 | 结构检查；枚举计数；数值等价；交叉核验；合成集；候选管理 |
| 06 跑完整流程 | 23–25 | 账本与续跑；失败分类；全流程清单 |

## 使用顺序

先按顺序读 01–10，认识文件、题目和单元格。再读 11–16，知道模型能做什么、会错什么。最后读 17–25，把验证和提交流程跑起来。每章末尾有练习，动手做一章再进下一章。
