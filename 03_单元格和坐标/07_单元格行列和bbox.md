# 07 单元格、行列和 bbox

[目录](../README.md)｜先修：[分数怎么算](../02_比赛的题目/06_分数怎么算.md)｜下一章：[合并单元格](08_合并单元格rowspan和colspan.md)

## 1. 单元格由四样东西描述

| 要素 | 记法 | 例子 |
|---|---|---|
| 行 | row，从 0 起算 | 0 是第一行 |
| 列 | col，从 0 起算 | 0 是第一列 |
| 文字 | 原文逐字 | `Stitch type` |
| 位置框 | bbox = [x0, y0, x1, y1] | 左上角和右下角像素坐标 |

**0 基索引（0-based index）**是全流程约定：第 1 行记作 row=0。代码里 `r..r+rs-1` 的写法和它配套。

## 2. bbox 的合法性只有四条

1. 边界：0 ≤ x0 < x1 ≤ 图宽，y 同理。
2. 非空：面积大于 0。
3. 不重叠：同层单元格互不压叠。
4. 自洽：声明的行列范围能装下所有格子。

模型报坐标时最常见的错叫 **off-by-one**：把最大下标当尺寸。3 行表的行号是 0、1、2，模型报 nrows=2，越界格子恰好等于 2。见到"越界值 == 声明尺寸"就按 +1 修。

## 3. 行列归属怎么查

一个值的**字段归属（field owner）**看两处：它所在行的行标签，它所在列的列头。两个证据要分开拿，别用直觉。

## 4. 每次拿到结构输出照这个顺序查

1. 每个 bbox 过四条合法性。
2. 检查 nrows/ncols 与格子自洽。
3. 任取三格，验文字和位置对得上。
4. 再谈用这份数据答题。

## 5. 练习

1. 画一个 3×4 表，给每格标 row/col 和 bbox。
2. 造一个 off-by-one 例子，写出修复规则。
3. 给"性别：男"这组键值对标出两个 bbox，并验证同行相邻。
