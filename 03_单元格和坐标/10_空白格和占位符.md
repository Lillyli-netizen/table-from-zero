# 10 空白格和占位符

[目录](../README.md)｜先修：[多层表头和键值表](09_多层表头和键值表.md)｜下一章：[多模态模型吃图](../04_让模型读表/11_多模态模型吃图base64和压缩.md)

## 1. 空白的三种身份

| 情况 | 正确读法 |
|---|---|
| 单元格真的空 | 空字符串，什么都不填 |
| 表格用空表示 0 | 只有表格有约定时才当 0 |
| 值被符号替代 | 抄符号本身 |

**空白不默认等于 0**。这条规则在比赛里反复救场：依赖"空白=0"猜的答案没有依据，一律保留原值。

## 2. 占位符白名单

合法的非数值占位符只有一小撮：

```
--  -  —  –  −  /  N/A  n/a  NA
```

number 题解析到这些放行，其余非数值一律打回。没有白名单，"暂无" "略" 会混进数值答案。

## 3. 空白格进结构题

合成验证集专门做一类含空单元格的表（blank 类）。结构输出要求空格也占位：格子存在、文字为空。漏掉空格会让网格闭合检查失败。

## 4. 判空白的三步

1. 看格子是否存在（bbox 有无）。
2. 看表格有没有"空=0"的约定（如合计行的减法关系）。
3. 都没有就当空白处理，答案留空或保留占位符。

## 5. 练习

1. 造一个含 3 个空白格的 4×4 表，写结构输出。
2. 判断 `--`、`暂无`、`0.00` 各属于哪种情况。
3. 找一个"空白=0"的合法场景：合计行减法能对上。
