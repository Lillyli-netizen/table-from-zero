# 17 结构检查：网格闭合、越界、重叠

[目录](../README.md)｜先修：[模型常犯的错](../04_让模型读表/16_模型常犯的错.md)｜下一章：[枚举计数](18_枚举计数程序数数模型别报数.md)

## 1. 四项检查，全过才算结构合法

| 检查 | 规则 |
|---|---|
| 边界 | bbox 在图内且面积非零 |
| 重叠 | 两格不覆盖同一 (row, col) |
| 覆盖 | 声明范围内无缺格（网格闭合） |
| 自洽 | nrows = max(row+rowspan)，ncols = max(col+colspan) |

CSV 格式合法、列数一致，这些都只是"能解析"。**能解析**和**结构合法**是两件事，还需核对内容、来源与题意，结构合法本身不能证明答案正确。

## 2. 修尺寸不修内容

发现 nrows 写小（off-by-one），可计算覆盖范围作为诊断，仅确认错误在尺寸时才修正。但文字、索引、bbox 一律不动，缺格不填、冲突不删。修复只改"声明的框架"，内容改动必须有新证据。

## 3. 离线重放的标准流程

1. 构造正反样例先验证检查器：正常网格过、重叠/缺列/错误跨度/截断全被拦。
2. 检查器可信后，对全部历史响应统一重放。
3. 每题记录逐项结果，存成审计文件。

真实重放结果：10 份密集表响应，修尺寸后仍有 4 份缺格、2 份 bbox 非法、4 份截断——结构合法 0 份。合成集上 100% 合法的链路，真实表上从零开始。

## 4. 练习

1. 写一个网格闭合检查函数，输入 cells 输出缺格清单。
2. 构造 8 个正反样例测你的检查器。
3. 把"能解析"和"结构合法"的区别讲给同伴听。
