# 21 合成验证集：自己画表考模型

[目录](../README.md)｜先修：[交叉核验](20_交叉核验局部证据加双路.md)｜下一章：[候选哈希和回退](22_候选哈希和回退.md)

## 1. 为什么自己画表

模型的真实能力需要先在有标准答案的题上量出来。隐藏测试图没有答案，历史答案不能抄——自己画表是唯一的干净考卷。

## 2. 生成即答案

用 PIL 画表，画的过程直接产出真值：

| 生成项 | 来源 |
|---|---|
| 单元格 bbox | 绘制坐标 |
| 合并关系 | 构造参数 rs/cs |
| 答案 | 构造时算出 |
| 题目 | 五类模板 |

生成的表四类各三张：键值表、多层表头、合并单元格、空白格。题目五类：最左表头、最右表头、字段归属、指定行列、数组提取。

## 3. 开发集和留出集

12 张图分两半：4 张开发，8 张留出。开发阶段只许调一次规则，留出集不许逐图调参。真值只交给本地评分程序，绝不进模型请求。

## 4. 合成成绩的外推边界

实测：合成集结构合法率 100%、答案 95%。真实表上同链路合法率 0/10——失败全在输出预算和网格不自洽。合成达标只证明"这套方法能处理这四类结构"，外推到真实表要重新验证。

## 5. 练习

1. 用 PIL 画一张 3×4 合并表，记录全部真值。
2. 设计第五类题目并写出真值生成逻辑。
3. 解释为什么真值不能进模型请求。
