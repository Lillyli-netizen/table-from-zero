# 19 数值等价：94、94.0 和 (100)

[目录](../README.md)｜先修：[枚举计数](18_枚举计数程序数数模型别报数.md)｜下一章：[交叉核验](20_交叉核验局部证据加双路.md)

## 1. 数值题用 Decimal 比较

`94` 和 `94.0` 数值相等。比较时去千分位逗号，转 Decimal：

```python
from decimal import Decimal
Decimal("94,000".replace(",", "")) == Decimal("94000")   # True
```

等价的改动不算改动：把 `94` 改成 `94.0` 不产生任何分数变化，白占一个改动名额。

## 2. 不适用等价的四类

| 类型 | 原因 |
|---|---|
| 标识符 | `00123` 的前导零有意义 |
| 电话号码 | 位数就是内容 |
| 固定精度要求 | 题干点名保留两位 |
| 字符串 | 逐字比较，`8,0` 和 `8.0` 不同 |

## 3. 会计括号和符号

`(100)` = −100，`$ 118,573` = 118573，`85.4%` = 0.854 或 85.4（看题干口径）。规则：

1. 读数时保留符号原文进 basis。
2. 提交时按 format 写规范值。
3. 平台对 number 做数值比较（实测），形态不扣分。

符号丢失是比形态更大的错误：`(100)` 读成 `100` 差 200。

## 4. 字符串的等价边界

去首尾空白可以；内部空格、大小写、相似字母（西里尔 е 与拉丁 e、† 与 ‡）一律视为不同。实测有两路答案只差一个西里尔字母，按不一致处理。
