# 20 交叉核验：局部证据加双路

[目录](../README.md)｜先修：[数值等价](19_数值等价9494点0和会计括号.md)｜下一章：[合成验证集](21_合成验证集自己画表考模型.md)

## 1. 局部证据契约

不要求模型输出整表，只要求输出题目相关部分：

```json
{"answers": [{"id": 455, "answer": "男", "target": "男",
              "bbox": [312, 17, 420, 52],
              "labels": [{"text": "性别", "bbox": [204, 17, 312, 52]}]}]}
```

以下字段形成可复查记录，还需验证引文与 bbox 真实性：答案、目标原文、目标 bbox、必要标签的 bbox 和位置关系。

## 2. 核验按题不按整图

1. 目标和标签的 bbox 过边界检查。
2. 原文引用逐字比对。
3. 位置关系：键值同行相邻、行列归属成立。
4. 单位、符号、口径一致。
5. 与另一路隔离作答，并记录两路共享的输入与模型依赖交叉比对。

## 3. 全局题要完整证据

"最右侧表头"必须有覆盖全部相关表头的枚举。一个目标框证不了"最右"。无关区域缺格不扣分，目标证据缺失照剔。

## 4. 一致 ≠ 正确

两路一致只记**交叉支持（cross support）**，原始响应永远保留。历史上两路一致后被更高证据推翻的例子存在（两路同时丢会计括号）。采纳是"目前最好的判断"，每条证据都留在原地可复查。

## 5. 实测战绩

局部证据+双路在 14 题上产出 1 题硬改动（性别：男，键值同行相邻的来源支持）；扩到 35 题产出 0 题——门槛没放，剔除原因全部留档。

## 6. 练习

1. 为一道字段归属题写局部证据契约。
2. 列出五项核验的拦截顺序。
3. 讨论什么时候两路一致仍要怀疑。
