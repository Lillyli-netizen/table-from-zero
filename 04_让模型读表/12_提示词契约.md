# 12 提示词契约

[目录](../README.md)｜先修：[多模态模型吃图](11_多模态模型吃图base64和压缩.md)｜下一章：[截断max_tokens和finish_reason](13_截断max_tokens和finish_reason.md)

## 1. 契约 = 任务 + 格式

一段提示词至少两段：让它做什么，让它按什么格式回。

```
你是表格信息抽取程序。
【表格文本开始】……【表格文本结束】
题目：……
只输出最终数值。
```

格式段是硬约束：number 只回数值，json_array 只回 JSON 数组。模型多解释一句，解析就多一分风险。

## 2. 结构输出的契约

要求模型输出整表结构时，契约要写死字段和索引约定：

```json
{"nrows": 3, "ncols": 4, "cells": [{"row": 0, "col": 0, "rowspan": 1, "colspan": 1, "text": "姓名", "bbox": [0, 0, 100, 30]}]}
```

三件事必须在契约里说死：**row/col 从 0 起算**、**rowspan/colspan 为格数最小 1**、**bbox 用像素坐标**。约定没写死，模型随手换口径，程序全部对不上。

## 3. temperature 设 0

表格读数要稳定，不要创造性。低 temperature 通常减少采样随机性，服务实现仍可能不完全确定。需要多样本投票的场合才临时调高。

## 4. 契约改一次，版本号进一版

提示词、解析规则、输入编码任一改动都记录新版本，旧输出保留为历史证据。比赛链路用 PROMPT_VERSION 记版本，缓存键包含源文件、页、裁图、提示词、模型和配置，只重算确实受影响的部分。混版本的输出不能混着投票。

## 5. 练习

1. 把"只输出最终数值"的契约补全成四种格式各一份。
2. 给结构输出契约加上"空白格也要占位"的要求。
3. 设计一个解析失败后的重问提示，只纠正格式。
